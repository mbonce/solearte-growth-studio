# Templates

Reusable Markdown templates for Wholesale-Ops growth work.

Copy a template into the relevant folder, fill it with FBA wholesale-specific context, and send it through QA before external use.

## Template Rules

- Replace every TODO before using externally.
- Add the workflow area and target seller.
- Mark unsupported claims as hypotheses.
- Keep sensitive pricing, compliance, account-health, and profit questions out of auto-generated copy.
- Record the destination folder when a template becomes a live asset.
