# Workflows

This folder defines how the Wholesale-Ops growth studio operates each week.

Each workflow should specify inputs, agents involved, outputs, and QA checkpoints. The goal is repeatable execution, not one-off content production.

## Workflow Standard

Each workflow should make ownership and handoffs explicit:

- Inputs.
- Agents involved.
- Output folder.
- Review checklist.
- Analytics or learning log destination.

## Default Cycle

Research informs positioning. Positioning informs content, outbound, sales, and website copy. Analytics and QA then update the next cycle.
