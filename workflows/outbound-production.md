# Outbound Production Workflow

## Inputs

- Prospecting criteria.
- ICP.
- Current offer.
- Approved sequences.
- Reply handling rules.

## Process

1. Build a small prospect list with fit evidence.
2. Select one sequence.
3. Personalize only with true public information.
4. Send and log outcomes.
5. Route replies using reply-handling rules.

## Outputs

- Prospect list.
- Sent batch.
- Reply log.
- Learning notes.

## Review

- Is the prospect likely an FBA wholesale seller?
- Is the message plain and specific?
- Is the next step low-friction?
