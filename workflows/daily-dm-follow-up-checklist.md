# Daily DM Follow-Up Checklist

## Morning

- [ ] Review new DMs from previous 24 hours.
- [ ] Classify each DM in `workflows/instagram-inbox-management.md`.
- [ ] Escalate pricing, account-health, demo, IP complaints, and integration questions.

## During Day

- [ ] Send scorecard first on first-response for scorecard requests.
- [ ] Add a qualifying question after sending scorecard link:
  - “Which section feels most painful right now?”
- [ ] Tag likely operators (`supplier pipeline`, `buy-list`, `replenishment`) for sales handoff.
- [ ] Capture exact seller language in `voice-of-customer/direct-quotes.md`.

## End of Day

- [ ] Close all low-risk replies from approved response set.
- [ ] Log unresolved items for founder review.
- [ ] Update `analytics/instagram-dm-performance.md`.
- [ ] Report at least one recurring pain phrase in the day log.
