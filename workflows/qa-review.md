# QA Review

Use this process for all content, outbound, sales, website, and DM copy.

## Checks

- Does it target FBA wholesale sellers?
- Does it accidentally sound like brick-and-mortar wholesaling?
- Does it make unsupported claims?
- Does it imply guaranteed profit?
- Does it overpromise Amazon compliance protection?
- Does it avoid get-rich-quick language?
- Does it focus on operational discipline?
- Is the CTA clear?
- Is the copy practical and specific?

## Review Status

- Approved: ready to use.
- Revise: useful but needs edits.
- Blocked: contains risk, wrong audience, or unsupported claims.

## Escalation

Human review is required for pricing, Amazon account health, IP complaints, suspensions, legal/compliance advice, refunds, billing, custom integrations, and profit guarantee questions.
