# Carousel Patterns

## Best Slide Structures

### Problem To Workflow

1. Painful hook.
2. What the seller thinks the problem is.
3. What the real workflow problem is.
4. Where the handoff breaks.
5. Required fields or stages.
6. Better operating principle.
7. CTA.

### Mistake Stack

1. Hook.
2. Mistake 1.
3. Mistake 2.
4. Mistake 3.
5. What those mistakes create.
6. What to do instead.
7. Scorecard CTA.

### Audit Checklist

1. Hook.
2. Supplier check.
3. Catalog check.
4. ASIN check.
5. Buy-list check.
6. Replenishment check.
7. DM prompt.

## Hook Slides

- Use a single blunt sentence.
- Make the workflow area obvious.
- Avoid vague founder language.
- Use "your" when the pain is recognizable.

## Progression Styles

- Messy current state -> hidden cost -> better workflow.
- Beginner belief -> operator reality -> checklist.
- Sourcing mindset -> operations mindset -> scorecard.

## CTA Placement

- Soft CTA on slide 6: "Save this before your next catalog review."
- Direct CTA on final slide: "Get the FBA Wholesale Ops Scorecard."
- Caption CTA: "Comment scorecard" or "DM OPS."

## Save Triggers

- Checklists.
- Required fields.
- Review states.
- Before/after workflow maps.
- "Use this before..." framing.

## DM Triggers

- "Which workflow is messiest?"
- "DM CATALOG if this is your bottleneck."
- "Comment scorecard."
- "Reply with the tab that is most out of control."
