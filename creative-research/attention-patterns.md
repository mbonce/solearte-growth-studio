# Attention Patterns

## First-Second Attention

- Use a blunt pain line.
- Avoid clever but vague hooks.
- Put the workflow noun in the hook: catalog, buy list, VA, replenishment, supplier.

## Mid-Asset Retention

- Add a concrete example after the hook.
- Show the cost of the broken workflow.
- Use numbered fields or stages.
- Keep each slide or reel beat to one idea.

## End-Asset Conversion

- Give one action: comment scorecard, DM OPS, save, or book audit.
- Do not stack multiple CTAs.
- Match CTA to intent.

## Pattern To Avoid

- Starting with "Amazon sellers need systems."
- Generic ecommerce motivation.
- Long captions that carry all the value while the visual is weak.
- Reels that talk about operations without naming a specific workflow.
