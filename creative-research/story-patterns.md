# Story Patterns

## Poll Pattern

- Frame 1: name workflow pain.
- Frame 2: binary poll.
- Frame 3: explain why it matters.
- Frame 4: CTA to DM or scorecard.

Example:

- "Do you reorder from a system or memory?"
- Poll: System / Memory.
- "Replenishment needs updated assumptions."
- "DM REORDER for the scorecard."

## Question Sticker Pattern

- Ask about the messiest workflow.
- Follow with a useful reply.
- Log exact wording in voice-of-customer files.

## Quiz Pattern

- Test an operating principle.
- Reveal the answer.
- Offer scorecard section.

## Behind-The-Workflow Pattern

- Show a messy handoff.
- Show a cleaner version.
- Ask if their team has the same issue.

## Story Quality Rules

- One decision per frame.
- Use plain words.
- Avoid long explanations.
- Every sequence should produce a reply, click, or insight.
