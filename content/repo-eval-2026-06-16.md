## Visual Read

1. `open-carrusel`: Best ready-made fit for aggressive Instagram-feed creative. The HTML slide model supports big hooks, angled labels, and fast format changes.
2. `html-to-image`: Best for a browser/editor workflow. The paper-and-phone style shows it can capture richer DOM compositions cleanly.
3. `satori`: Best for repeatable, fast, controlled cards. The output is crisp and editorial, but it is less expressive than full browser rendering.
4. `canva-clone`: Best if manual canvas editing matters. The shipping-label/cardboard board now reads very differently from the HTML renderers.
5. `reelstack`: Useful native image-gen package with brand tokens and multiple built-in templates. Its output is clean but more restrained, so it would need custom templates for a louder creator-feed direction.

- Visual audit checked for blank cells, catalog-code jargon, slash footer copy, and weak Amazon context.

## Recommendation

For a practical Wholesale Ops Instagram graphic workflow, start with the Open Carrusel or html-to-image approach: HTML/CSS templates rendered by a browser. It gives the best balance of visual polish, controllability, and automation.

Use Satori when speed and deterministic text cards matter more than CSS fidelity.

Use Fabric/canva-clone only if manual editing becomes important enough to justify a heavier editor surface.

Use ReelStack's `image-gen` module as a useful reference for brand-tokenized templates, but it needs stronger custom templates to match the aggressive FBA creator-feed direction.
