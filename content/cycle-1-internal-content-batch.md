## Carousel 1

- Title: A Spreadsheet Can Work Until It Has to Run the Whole Wholesale Workflow
- Target pain: Spreadsheet workflows become fragile as supplier catalogs, VA work, buy-list decisions, PO status, shipment notes, replenishment reminders, and team handoffs accumulate.
- Slide-by-slide copy:
  1. A spreadsheet can work.
  2. The issue starts when it has to carry the whole wholesale workflow.
  3. Suppliers, catalog review, buy-list approval, PO status, shipment notes, replenishment reminders, and team handoffs all start piling into the same place.
  4. The problem is not the spreadsheet. The problem is when workflow context has nowhere clear to live.
  5. As volume increases, weak handoffs get easier to miss.
  6. Each review item should have status, owner, reason, next action, and review history.
  7. A clean buy list should explain how each item got there.
  8. Start by scoring your current ops workflow.
- Caption: A spreadsheet can be useful. It gets fragile when it becomes the only place for supplier context, review status, buy-list decisions, and team handoffs.

## Carousel 3

- Title: The Workflow Needs Review States
- Target pain: VA/team handoffs lack approval control and operator visibility.
- Slide-by-slide copy:
  1. The workflow needs review states.
  2. "Find good products" creates unclear work if the review path is not defined.
  3. "Move approved ASINs here" can hide judgment calls when the process has no approval state.
  4. The operator needs to see what was reviewed, paused, rejected, blocked, and why.
  5. A useful handoff has owner, status, reason, date, and next action.
  6. This protects context when the team changes or the catalog gets reopened.
  7. Delegation works better when the workflow carries the decision history.
  8. Start with the scorecard. Find the weakest handoff.
- Caption: Team review gets easier to manage when the workflow has states. Intake, reviewing, needs owner review, approved, rejected, blocked, and ready for next action make handoffs easier to audit.
- CTA: Get the FBA Wholesale Ops Scorecard.
- Suggested visual layout: Checklist layout; status lane mockup: New / Reviewing / Needs Owner / Approved / Rejected.
- Interaction prompt: Diagnostic only; no comments or DMs approved.
- Evidence label: `VA/team handoff` lane. Confidence: Medium.
- QA notes: Internal draft only. Process-first language only; do not blame VAs or promise outcomes. Requires QA and human approval.
