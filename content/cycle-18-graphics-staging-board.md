1. A matched row is not an approved buy.
2. Approval state still needs owner, reason, and next action.
3. The approval chain has to stay with the row as it moves through review.
4. Review is only reusable when the decision context stays with the row.
5. The reviewer checkpoint has to survive.
6. If a row comes back into review, the reopen reason has to survive too.
7. Only then is the row handoff-ready.
