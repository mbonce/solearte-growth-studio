# Agents Index

## Role

Provides the folder-level operating context for Wholesale-Ops growth studio agents.

## Goal

Help each agent use shared marketing skills while staying grounded in Amazon FBA wholesale operations.

## Primary Inputs

- `.agents/marketingskills`
- `product/product-marketing.md`
- `product/icp.md`
- `instagram/content-strategy.md`
- `audience-research/README.md`
- `creative-research/README.md`
- `research/customer-language.md`
- `workflows/weekly-growth-cycle.md`

## Primary Outputs

- Correct agent selection
- Consistent task routing
- Clear QA expectations
- Shared operating context

## MarketingSkills Used

- Agent orchestration
- Product marketing
- Customer research
- Content strategy
- Sales enablement

## Workflow

1. Start with product context.
2. Route audience understanding, creator analysis, hooks, save/share analysis, and voice-of-customer work to `audience-research-agent.md`.
3. Route launch content, carousels, reels, stories, DMs, and top-of-funnel engagement to `instagram-content-agent.md`.
4. Select the agent card that matches the task.
5. Pull reusable technique from `.agents/marketingskills`.
6. Create or revise the asset in the matching repo folder.
7. Run the QA agent before external use.

## Quality Checklist

- Every output targets Amazon FBA wholesale sellers.
- Generic marketing advice is adapted to Wholesale-Ops.
- Claims stay practical and supportable.
- Work lands in the correct folder.

## Escalation Rules

- Escalate tasks that involve pricing, Amazon account health, compliance, IP complaints, suspensions, or unsupported product capabilities.
- Escalate if the requested audience is not FBA wholesale sellers.

## Success Metrics

- Agents use consistent context.
- Outputs are easier to review.
- Weekly growth work is routed cleanly.
