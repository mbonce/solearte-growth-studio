# Agents

SOLEARTé-specific agent cards. Each wraps generic MarketingSkills technique with the artist's context, constraints, and outputs.

| Agent | Owns | Reads first |
|---|---|---|
| `orchestrator-agent.md` | Weekly cycle, routing, priorities | everything in `product/` |
| `brand-narrative-agent.md` | Story, voice, positioning, claim boundaries | `product/brand-brief.md` |
| `audience-research-agent.md` | Personas, VOC capture, research loop | `research/`, `voice-of-customer/` |
| `instagram-content-agent.md` | Reels, carousels, captions, stories | `instagram/`, `content/`, `creative-research/` |
| `instagram-dm-agent.md` | Comment and DM handling, triage | `instagram/dm-*.md` |
| `commission-sales-agent.md` | Inquiry to proposal to delivery | `sales/` |
| `collab-outreach-agent.md` | Venue, brand, org outreach | `outbound/` |
| `shop-agent.md` | Carry Your Colors listings, product content, order follow-up | `product/offers.md`, `website/` |
| `community-impact-agent.md` | RMIAN line accuracy, Denver presence, community respect | `product/brand-brief.md` |
| `analytics-agent.md` | Weekly report, pipeline, experiments | `analytics/` |
| `qa-agent.md` | Accuracy, voice, permission, risk | `workflows/qa-review.md` |

All agents: the artist approves anything external. No agent invents facts, quotes, prices, or stories.
