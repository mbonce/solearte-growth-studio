# Manual Fallback Runbook

Use this when any automation is unavailable.

## Daily launch operations

1. Open `launch/launch-command-center.md`.
2. Confirm `Instagram` profile and link in bio are live.
3. Publish assets manually from `launch/week-1-publishing-calendar.md`.
4. Reply to DMs using:
   - `instagram/dm-response-library.md`
   - `workflows/instagram-inbox-management.md`
5. Log DMs and pain points in `analytics/research-insights-log.md`.
6. Confirm scorecard requests manually from `lead-magnets/scorecard-follow-up-sequence.md`.
7. Record day totals in:
   - `analytics/content-performance.md`
   - `analytics/instagram-dm-performance.md`
   - `analytics/scorecard-funnel-tracking.md`
   - `analytics/workflow-audit-funnel-tracking.md`
8. Run founder review with:
   - `launch/week-1-operating-plan.md`
   - `agent-ops/daily-agent-standup.md`

## Failure handling

- If a high-risk DM arrives, route to founder immediately.
- If no metrics file exists, create entry placeholders and continue.
- If posting approval is missing, postpone publish until approved.
