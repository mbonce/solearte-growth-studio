# Instagram Visual Style Guide

## Style Direction

- Dark mode.
- Clean typography.
- Operational command center feel.
- Dashboard screenshots where available.
- Workflow diagrams.
- Checklist layouts.
- Spreadsheet callouts.
- Whiteboard logic.
- Minimal colors.
- Practical operator aesthetic.

## Visual Language

- Use tight, readable headlines.
- Show process arrows, status labels, checklists, and review states.
- Use spreadsheet screenshots or mock spreadsheet callouts only when they illustrate workflow pain.
- Keep slides useful enough to save.
- Make the first slide instantly clear without needing the caption.

## Color And Layout

- Base: near-black, charcoal, white.
- Accent: one operational color per post, such as green for approved, amber for review, red for risk, blue for workflow.
- Avoid busy gradients.
- Use consistent spacing and grid alignment.
- Keep copy short enough to read on mobile.

## Avoid

- Glossy startup illustrations.
- Pastel SaaS graphics.
- Guru aesthetics.
- Fake luxury imagery.
- Generic ecommerce templates.
- Fake dashboards that imply undocumented product features.
- Customer screenshots or real user data without approval.

## Format Notes

- Carousels: one idea per slide.
- Reels: strong first-frame text plus clear spoken hook.
- Stories: polls, questions, sliders, and reply prompts.
- Memes: operator pain first, joke second.
