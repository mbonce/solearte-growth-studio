# Manual Engagement Workflow

## Comment Replies

- Use low-risk templates from `instagram/comment-reply-library.md`.
- Start with recognition of their situation.
- Add one practical question max.
- Move to scorecard only after the situation is acknowledged.

## DM Handling

- `scorecard request` → send link first + qualifying question.
- `workflow pain` → ask one specific stage.
- `qualified operator` → ask how they score the weak area.
- `beginner` → recommend timing and clarify fit.
- `pricing/demo/account-health/integration/profit guarantee` → route founder.

## When to Ask Questions

- Ask a qualifying question when:
  - user asks for the scorecard,
  - user shares a painful workflow state,
  - conversation moves toward audit readiness.

- Do not ask multiple questions in a row. One is enough.

## When to Push Scorecard

- When user mentions catalog backlog, buy-list confusion, supplier process, replenishment drift, or VA handoff ambiguity.
- Always keep scorecard as first practical step.

## When to Offer Workflow Audit

- After scorecard request + one clear weak section is identified.
- When seller describes repeated operational failures and asks for structured fix.
- Offer: `Book an ops workflow audit`.

## When to Escalate Human-only

- Any pricing discussion.
- Any account-health/risks request.
- Demo requests.
- IP or compliance concerns.
- Angry/demanding posts with unresolved legal or compliance pressure.
- Anything implying refunds or billing dispute.
