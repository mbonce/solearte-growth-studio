# Link-In-Bio Plan

## Goal

Route Instagram attention into scorecard requests first, workflow audits second.

## Link Order

### Primary

1. FBA Wholesale Ops Scorecard
   - Label: `Get the FBA Wholesale Ops Scorecard`
   - Purpose: primary conversion.
   - Destination: scorecard page.

### Secondary

2. Book workflow audit
   - Label: `Book an ops workflow audit`
   - Purpose: high-intent sellers.
   - Destination: booking link.

3. What is Wholesale-Ops?
   - Label: `What is Wholesale-Ops?`
   - Purpose: explain positioning.
   - Destination: homepage or explainer.

4. Instagram DM prompt
   - Label: `DM OPS if your wholesale workflow is messy`
   - Purpose: start conversation.
   - Destination: Instagram DM.

## Link Copy Rules

- Keep labels action-oriented.
- Put scorecard first.
- Do not mention pricing in link labels.
- Do not imply profit or account protection.

## Tracking Notes

Track daily:
- Link clicks.
- Scorecard clicks.
- Audit clicks.
- DMs after profile visits.
