# Website

Website copy should sell the operating problem clearly before explaining modules.

The audience is Amazon FBA wholesale sellers. Avoid language that attracts traditional wholesalers, retail stores, warehouse operators, or distributor ERP buyers.

## Website Standard

Every page should make three things obvious:

- Wholesale-Ops is for Amazon FBA wholesale sellers.
- The product is about operations after sourcing starts working.
- The next step is either the scorecard or an ops workflow audit.

## Page QA

Before publishing page copy, check that it does not mention undocumented integrations, customer logos, case studies, metrics, profit guarantees, or Amazon account-protection claims.
