# Run Log

Use this file to track each autonomous internal production cycle. Do not record private details or external-contact actions here.

## Schema

| Field | Purpose |
|---|---|
| `cycle_id` | `YYYY-MM-DD-C01`, `C02`, etc. |
| `cycle_window` | 6-hour window covered. |
| `owner_agent` | Agent accountable for entry. |
| `research_question` | Question the cycle tried to answer. |
| `sources_reviewed` | Count and source types only; no private details. |
| `evidence_captures` | Count of captured research rows. |
| `workflow_area` | Spreadsheet, VA workflow, supplier follow-up, margin, replenishment, objections, disqualification. |
| `pain_clusters` | Named pain themes observed or explored. |
| `candidate_hooks` | Draft internal hooks, not public claims. |
| `candidate_objections` | Objections found or hypothesized. |
| `content_outputs` | Drafts created by type. |
| `qa_status` | Not reviewed, needs revision, approved for internal queue, or blocked. |
| `risk_flags` | Claims, pricing, compliance, account health, unsupported product capability. |
| `confidence_tier` | Seed, Low, Medium, or High. |
| `decision` | Keep researching, draft asset, revise positioning, or block. |
| `next_research_question` | Question handed to next cycle. |
| `blockers` | Missing evidence, missing product proof, human review needed. |

## Confidence Rules

- `Seed`: internal hypothesis from strategy/backlog only. Never treated as market evidence.
- `Low`: one weak or indirect signal, or plausible pain with no repeated source support.
- `Medium`: repeated pattern across at least 3 relevant public sources, or 2 stronger VOC-style sources from the ICP.
- `High`: repeated ICP evidence plus observed response behavior such as replies, scorecard downloads, audit requests, interviews, or approved customer conversations.
