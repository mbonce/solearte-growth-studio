# Shared Agent Resources

`.agents` contains shared resources used by the Wholesale-Ops agent system.

## MarketingSkills

`marketingskills` is an external Git submodule from:

`https://github.com/coreyhaines31/marketingskills`

Use it as the shared marketing skill library for research, positioning, content, outbound, sales enablement, and growth workflows.

## Wholesale-Ops Wrappers

The files in `/agents` wrap those generic skills with Wholesale-Ops-specific context:

- Amazon FBA wholesale sellers only.
- Operations command center positioning.
- Supplier, catalog, ASIN, buy-list, PO, FBA shipment, replenishment, VA workflow, and risk-control language.
- No brick-and-mortar wholesale, distributor ERP, retail store, or warehouse-operator positioning.
