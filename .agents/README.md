# Shared Agent Resources

`.agents` contains shared resources used by the SOLEARTé agent system.

## MarketingSkills

`marketingskills` is an external Git submodule from `https://github.com/coreyhaines31/marketingskills`.

Use it as the shared marketing skill library for research, positioning, content, outreach, sales enablement, and growth workflows.

## SOLEARTé Wrappers

The files in `/agents` wrap those generic skills with SOLEARTé-specific context:

- One Denver-based contemporary artist, speaking in the first person where the artist speaks.
- Saturated portraiture, original paintings, commissions, collaborations, and Carry Your Colors wearable art.
- Themes of identity, migration, resilience, movement, and unapologetic individuality.
- 15% of Carry Your Colors proceeds to Rocky Mountain Immigrant Advocacy Network.
- No invented press, galleries, testimonials, metrics, or stories.

## Use Boundary

MarketingSkills is a technique library, not the source of truth. If a MarketingSkills example suggests fake metrics, urgency tricks, discount spirals, generic "art brand" claims, or testimonials, adapt or discard it unless SOLEARTé has documented evidence.
