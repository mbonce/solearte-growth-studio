# Handoff Map

## Research To Creative

Audience Research Agent -> Instagram Content Agent: hooks, pain patterns, visual trends, save/share/DM triggers.

FBA Customer Research Agent -> Product Marketing Agent: seller language, objections, workflow complaints.

## Creative To QA

Instagram Content Agent -> QA Agent: carousels, reels, stories, memes, captions, CTAs.

FBA Ops Content Agent -> QA Agent: repurposed X, LinkedIn, newsletter, long-form content.

## Engagement To Sales

Instagram DM Agent -> Sales Enablement Agent: qualified prospects, demo requests, workflow audit interest.

Outbound Agent -> Sales Enablement Agent: positive replies and audit-ready prospects.

## Specialist To Content

Supplier Workflow Agent -> Instagram Content Agent: supplier-pipeline diagnostics and hooks.

Catalog Analysis Agent -> Instagram Content Agent: catalog, ASIN review, and buy-list handoff logic.

Profitability Agent -> Instagram Content Agent: margin and replenishment angles.

Account Risk Agent -> QA Agent: risk-safe language and blocked claims.

## Analytics Back To System

Analytics Agent -> Orchestrator Agent: daily launch metrics and blockers.

Analytics Agent -> Audience Research Agent: repeated pain patterns and top-performing hooks.

Analytics Agent -> Product Marketing Agent: objections and positioning implications.
