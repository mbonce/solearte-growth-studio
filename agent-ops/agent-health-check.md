# Agent Health Check

Use this checklist before launch week and every Friday.

## Context

- [ ] Agent has launch-mode sections.
- [ ] Agent has activation prompt.
- [ ] Agent knows context loading order.
- [ ] Agent knows output contract.

## Positioning

- [ ] Agent targets Amazon FBA wholesale sellers.
- [ ] Agent avoids brick-and-mortar wholesale language.
- [ ] Agent avoids generic SaaS and course-seller tone.
- [ ] Agent uses scorecard CTA where relevant.

## Risk

- [ ] Agent avoids profit guarantees.
- [ ] Agent avoids Amazon compliance guarantees.
- [ ] Agent knows human approval rules.
- [ ] Agent knows escalation levels.

## Handoffs

- [ ] Agent knows primary handoff.
- [ ] Agent routes public copy to QA.
- [ ] Agent routes qualified prospects to sales/workflow audit.
- [ ] Agent sends metrics or insights to analytics.

## Launch Readiness

- [ ] Daily responsibilities are clear.
- [ ] Weekly responsibilities are clear.
- [ ] First 5 launch tasks are defined.
- [ ] No blocker remains unresolved.
