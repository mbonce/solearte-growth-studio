# Competitors

This folder tracks the creator, content, and positioning landscape around FBA wholesale.

Use it to identify:

- Which creators dominate beginner attention.
- Which accounts focus only on sourcing.
- Which creators ignore operations.
- Which formats get saves, shares, comments, and DMs.
- Where Wholesale-Ops can own the operational discipline angle.

## Research Rule

Do not invent performance metrics. Record visible patterns, exact hooks, observed comments, and confidence level.

## Review Cadence

- Weekly: review Instagram and X creator posts.
- Biweekly: review YouTube videos and comments.
- Monthly: update positioning gaps.
