# Lead Magnets

Lead magnets should diagnose FBA wholesale operating pain and route qualified sellers toward a workflow audit.

The main asset is The FBA Wholesale Ops Scorecard. It should help sellers see weak spots across supplier pipeline, catalog intake, ASIN review, buy-list workflow, margin tracking, POs, shipments, replenishment, VA accountability, and risk control.

## Lead Magnet Standard

Each asset should:

- Give the seller a useful self-diagnosis.
- Reveal workflow pain without shaming the operator.
- Avoid promising profit, compliance outcomes, or account protection.
- Create a natural next step into a workflow audit.
- Capture language that can improve positioning.

## Follow-Up Rule

Follow-up should ask about the lowest-scoring workflow first. Do not push a demo before understanding whether the seller has active FBA wholesale complexity.
