# Day 3 Posting Playbook

## Day 3 Playbook (Instagram)

**Asset:** Carousel 2 — A Supplier Catalog Is Not an Opportunity Until It Has Workflow

## 1) Objective

Show the second core failure mode (catalogs without workflow), collect stronger operational phrases, and continue scorecard funnel movement.

## 2) Target Audience

Amazon FBA wholesale sellers with VAs or sourcing teams managing supplier catalogs and buy-list decisions through spreadsheets.

## 3) Post timing placeholder

- Preferred window: Week-1 Day 3, late morning local time (placeholder)
- Alternative window: 1-hour later if founder is handling escalations

## 4) Carousel asset checklist

- [ ] `design-ready-carousel-2.md` approved and exported.
- [ ] Post caption and slide order locked.
- [ ] Story sequence queued: Buy-list confusion.
- [ ] Scorecard CTA present on final slide.
- [ ] DM response set includes catalog-specific opening.

## 5) Caption

`A supplier catalog is not an opportunity unless the workflow keeps it moving.`

`Without intake, qualification, and ownership, teams carry the same catalog repeatedly through messy loops.`

`Comment “SCORECARD” or DM “CATALOG” for the FBA Wholesale Ops Scorecard.`

## 6) CTA

Primary CTA: `Comment “SCORECARD” or DM “CATALOG” for the FBA Wholesale Ops Scorecard.`

Secondary CTA: `Which section is weakest: suppliers, catalogs, buy list, shipments, replenishment, VA workflow, or risk control?`

## 7) Story sequence after posting

- Sequence: Buy-list story
- First frame: “Can every buy-list item explain why it made the list?”
- Poll: “Who decides?”
- Learning frame: show 3 required fields (Decision owner, why approved, handoff action).
- Final frame: Scorecard CTA.

## 8) First-hour engagement checklist

- Prioritize catalog pain comments and workflow questions.
- Capture and save 5 exact user phrases in notes.
- Ask one clarifying question in the most relevant comment thread.
- Reply to repeated same question only once and cross-reference.

## 9) DM handling rules

- “I use catalogs heavily” comments: acknowledge and ask if catalogs have a clear decision owner.
- Workflow pain DMs: identify stage issue and ask one follow-up.
- Demo/price/integration/account-health: founder escalation.
- Route “this sounds useful” to scorecard link + first weak section question.

## 10) Comment handling rules

- Use “what hurts most this week?” for comments that indicate pain.
- Keep replies operational and specific.
- Mark likely launch-ready sellers with workflow keywords.

## 11) Metrics to capture

- likes
- saves
- shares
- comments
- profile visits
- link clicks
- DMs
- scorecard requests

## 12) End-of-day review checklist

- [ ] Catalog pain frequency score (0–5).
- [ ] Strongest one comment that reflects catalog-to-buy-list pain.
- [ ] Number of repeat seller phrases for Week 2 iteration.
- [ ] Escalation events and response timing.
- [ ] Update `analytics/day-3-metrics-log.md`.

## 13) What signals indicate strong positioning resonance

- Comments mention supplier pipeline friction before deciding.
- Multiple users use terms “catalog debt,” “no clear owner,” “stuck in review.”
- First-hour scorecard asks from buyers with active sourcing ops.

## 14) Operational note

Treat catalog feedback as launch learning input for content and DM prompts for the next week.
