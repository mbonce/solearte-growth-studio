# Launch

This folder is the Wholesale-Ops launch command center.

Use it to run launch week from one place: readiness, daily publishing, approvals, founder tasks, risk tracking, metrics review, and retrospective.

## Launch Objective

Launch Wholesale-Ops as the clearest Instagram-native voice on FBA wholesale operational discipline.

The target is Amazon FBA wholesale sellers with VAs or sourcing teams who are managing supplier catalogs and buy-list decisions through spreadsheets.

Core thesis:

FBA wholesale is not just sourcing. It is operations.

## Channel Strategy

Instagram is the primary launch channel.

Secondary channels can support credibility and repurposing, but launch execution starts on Instagram.

## CTA Strategy

Primary CTA:

- Get the FBA Wholesale Ops Scorecard.

Secondary CTA:

- Book an ops workflow audit.

## How To Use This Folder

1. Start each day with `launch-command-center.md`.
2. Check `approval-board.md` before publishing.
3. Check `risk-register.md` before replying to sensitive DMs.
4. Use `week-1-publishing-calendar.md` for the daily content schedule.
5. Use `manual-founder-tasks.md` for founder-only work.
6. End each day by updating metrics and blockers in `launch-command-center.md`.
