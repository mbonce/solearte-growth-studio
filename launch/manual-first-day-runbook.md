# Manual First-Day Launch Runbook

## Before Posting

1. Confirm `launch/first-post-approval-packet.md` is fully checked.
2. Confirm Instagram profile is live with:
   - Handle set.
   - Bio set.
   - Scorecard link placeholder present (`{{scorecard_link}}`).
   - Booking link placeholder present (`{{booking_link}}`).
3. Confirm QA passed for first carousel copy and visuals.
4. Open `workflows/instagram-inbox-management.md` and keep escalation rules visible.
5. Confirm 90-minute monitoring windows are free.

## First Post

- Publish: `Your FBA Wholesale Spreadsheet Is Becoming Technical Debt`.
- Use exact caption from packet.
- Add CTA exactly: `Comment "scorecard" or DM "OPS" for the FBA Wholesale Ops Scorecard.`
- Record publish timestamp.

## First Story

Post the linked Supplier Follow-Up story sequence immediately after Carousel 1:

1. Supplier follow-up opening.
2. Poll sticker.
3. Operational explanation frame.
4. Question sticker.
5. CTA: DM OPS.

## First Hour Monitoring

- 0–30 min:
  - Track first comments and DM replies.
  - Use only safe low-risk replies from:
    - `instagram/dm-response-library.md`
    - `instagram/engagement-replies.md`
- 30–60 min:
  - Confirm scorecard request replies include the scorecard link first.
  - Add one follow-up question only if no qualifying section reply yet.
  - Escalate pricing/account-health/IP/demo/integration/profit questions to founder.

## Scorecard DM Handling

For scorecard requests:

1. Send the scorecard link immediately.
2. Ask:
   `After you run it, send me your lowest-scoring section: suppliers, catalogs, buy list, shipments, replenishment, VA workflow, or risk control.`
3. Tag section replies in a note file.
4. If reply includes active operational pain, prepare handoff.

## Comment Handling

- Reply to comments with:
  - practical operator language,
  - one diagnostic question,
  - no hype or promises.
- If comment asks for pricing, demo, or account-health assurances, route to founder.
- Log all useful language in `voice-of-customer/direct-quotes.md`.

## End of Day Review

- Record metrics:
  - saves
  - shares
  - comments
  - story replies
- Record conversion:
  - scorecard clicks
  - scorecard requests
  - follow-up section replies
  - workflow audit interest
- Review:
  - any missed timing in scorecard delivery flow,
  - escalations handled,
  - one founder action to improve tomorrow.

## What Not to Automate Yet

- Do not auto-post without founder approval.
- Do not auto-send pricing/account-health/IP/demo/integration/profit responses.
- Do not auto-close any operational questions that need context.
- Do not run scheduled DMs without first review of the qualification question.
