# Manual Founder Tasks

These tasks should be completed personally by the founder or explicitly approved by the founder.

## Before Launch

- [ ] Choose Instagram handle.
- [ ] Set profile bio.
- [ ] Upload profile image.
- [ ] Add link in bio.
- [ ] Review scorecard page.
- [ ] Review first 5 posts.
- [ ] Approve DM replies.
- [ ] Confirm booking link.
- [ ] Confirm scorecard delivery path.

## During Launch

- [ ] Monitor high-risk DMs.
- [ ] Approve pricing responses.
- [ ] Approve demo responses.
- [ ] Approve account-health responses.
- [ ] Approve custom integration responses.
- [ ] Reply personally to high-fit prospects when needed.
- [ ] Do end-of-day metric review.

## End Of Week

- [ ] Review best-performing content.
- [ ] Review scorecard clicks.
- [ ] Review audit bookings.
- [ ] Review repeated pain points.
- [ ] Approve Week 2 theme.
