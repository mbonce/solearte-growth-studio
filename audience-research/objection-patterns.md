# Objection Patterns

Patterns across audiences. Full answers in `product/objections.md`.

| Pattern | Who | What is really being asked | Honest move |
|---|---|---|---|
| "How much?" before anything else | Commissioners | "Is this for people like me?" | Explain scoping, invite details, show finished work |
| "Will it look like them?" | Commissioners | "Will I be embarrassed?" | Show style clearly, set expectations early |
| "I've never bought art" | Collectors | "Am I allowed?" | Yes. Buy what you love. Say it. |
| "Is the donation real?" | Carriers | "Am I being used?" | State 15% to RMIAN exactly, link to the collection page |
| "Sizing?" | Carriers | "Will I have to return it?" | Add size guidance to the page |
| "Can you do it for exposure?" | Collaborators | "Can we underpay?" | Route to artist; default is fair scope |
