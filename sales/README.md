# Sales

Sales assets should diagnose operating pain first and show Wholesale-Ops as a workflow system second.

The sales motion starts with seller fit, maps the current workflow, identifies the messiest operating area, and recommends a pilot only when there is clear FBA wholesale workflow complexity.

## Sales Standard

Every sales conversation should establish:

- The seller is operating an Amazon FBA wholesale model.
- Supplier, catalog, buy-list, PO, shipment, replenishment, VA, margin, or risk workflow pain exists.
- The buyer understands Wholesale-Ops is workflow infrastructure, not a profit guarantee.
- Sensitive Amazon account-health questions are routed to human review.

## Demo Rule

Do not feature-dump. Show only the modules connected to the seller's stated workflow pain and close with a scoped pilot if there is clear fit.
