# Pilot Delivery Checklist

## Before Kickoff

- [ ] Pilot objective defined and documented.
- [ ] One workflow selected (single scope).
- [ ] Success criteria and owner assigned.
- [ ] 30-day calendar published.

## Weekly Pilot Operations

- [ ] Week 1: baseline map and workflow standard.
- [ ] Week 2: owner accountability updates.
- [ ] Week 3: exception handling and escalation loop.
- [ ] Week 4: outcome review and recommendation.

## Closeout

- [ ] Scorecard re-check on selected workflow.
- [ ] Compare baseline vs week-4 indicators.
- [ ] Record what remained manual and why.
- [ ] Decide pilot outcome:
  - proceed-to-beta
  - continue manual
  - redesign scope
- [ ] Update conversion path to SaaS beta if approved.
